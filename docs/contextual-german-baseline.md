## Results

The corpus contains 16 deliberately difficult sentence-level targets. It is a
regression corpus, not a representative estimate of German prose.

| Stage | Correct | Rate |
| --- | ---: | ---: |
| ZDL contextual lemma/POS | 13/16 | 81.25% |
| Expected analysis present after augmentation | 16/16 | 100% |
| Fused primary | 14/16 | 87.50% |

The measured progression is:

| Pipeline | Morphology covered | Fused primary |
| --- | ---: | ---: |
| DWDSmor Open only | 11/16 | 10/16 |
| Open + de-DE forms | 15/16 | 13/16 |
| Forms + finite separable recombination | 16/16 | 14/16 |

C08a recovers `geschrieben`, `geschriebene`, `Goethe`, and `hub`. C08b uses the
ZDL `PTKVZ` tag and validates `aufstehen` against morphology before attaching it
to the unchanged `steht` token offsets. The original sentence-initial `Laden`
fixture ended in *ein* and therefore actually expressed `einladen`; C08b exposed
that bad gold annotation, so the fixture now tests unsplit `laden` without the
particle.

## Remaining failures

| Case | Mechanism |
| --- | --- |
| Imperative *Liebe deinen Nächsten* | ZDL predicts noun `lieb`; morphology contains verb `lieben`, but policy ranking selects noun `Liebe` |
| Archaic *hub* | Inventory contains exact verb `heben`; ZDL emits `OTHER`, while case-folded nouns `Hub` win on lemma agreement |

These are ranking failures, not coverage failures. They stay explicit rather
than being hidden by spelling guesses. U08's
[production grammar evaluation](contextual-grammar-production-evaluation.md)
retains both failures and documents additional model/ranking limitations rather
than introducing a narrow surface-specific rule.

## Resource and ownership decision

The de-DE form inventory is compiler-only. Loading it constructs exact and
folded Python indexes once so full-book analysis performs O(1) form lookup
without repeated archive reads. Definition text never participates in
morphology or canonical identity. The index and ZDL model are not uploaded, so
this host heap cost does not change firmware, EPUB, or SD-card RAM budgets.

DWDSmor remains the deterministic inflection and word-formation backbone; the
form inventory supplies missing lexical candidates, and ZDL ranks their union.
The schema-2 baseline additionally records normalized contextual features and
the v5 grammar descriptor/status for every target. Production cutover remains
blocked on the firmware, migration and hardware gates in the contextual task
board.
