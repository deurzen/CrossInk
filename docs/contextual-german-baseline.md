# Contextual German Baseline

## Pinned providers

- DWDSmor 0.18.0 Open Edition
- `de-zdl-lg` 4.0.0 static model
- spaCy 3.8.14
- Contextual analysis policy 1

The measured source is
`test/data/contextual/german-ambiguity-baseline.json`, generated by:

```sh
.cache/contextual/.venv/bin/python \
  scripts/dictionary/contextual/evaluate_german_corpus.py \
  --output test/data/contextual/german-ambiguity-baseline.json
```

## Results

The corpus contains 16 deliberately difficult sentence-level targets. It is a
regression/evidence corpus, not a representative estimate of all German prose.

| Stage | Correct | Rate |
| --- | ---: | ---: |
| ZDL contextual lemma/POS | 13/16 | 81.25% |
| Expected analysis present in DWDSmor Open | 11/16 | 68.75% |
| Fused primary over every target | 10/16 | 62.50% |
| Fused primary when morphology covers target | 10/11 | 90.91% |

## Observed failures

| Case | Mechanism |
| --- | --- |
| Imperative *Liebe deinen Nächsten* | ZDL predicts noun `lieb`; DWDSmor contains the verb, but contextual ranking chooses the noun |
| Verbal *geschrieben* | ZDL is correct; Open Edition emits no morphology candidate |
| Adjectival *geschriebene* | ZDL is correct; Open Edition emits no morphology candidate |
| Finite separable *steht … auf* | Both providers return base `stehen`; sentence-level particle recombination is required for lexical `aufstehen` |
| Proper name *Goethe* | ZDL identifies a proper noun; Open Edition emits no candidate |
| Archaic *hub* | Neither pinned provider resolves `heben` |

## C08a form-inventory augmentation

The retained de-DE bundle (`008b41d0-021c-591b-b16e-87573a017dfa`, archive
SHA-256 `5ae190802e85113ba192319b18c33e65ab1cd83a0f82a6e1154e824ba6a259ea`)
was then loaded as a compiler-only morphology inventory. Its 667,970 forms add
exact and case-folded candidates with explicit provenance; definition text does
not enter analysis.

| Stage | Open only | Open + de-DE forms |
| --- | ---: | ---: |
| Expected morphology present | 11/16 | 15/16 |
| Fused primary correct | 10/16 | 13/16 |

This recovers `geschrieben`, `geschriebene`, `Goethe`, and `hub`. The archaic
`hub` remains misranked because ZDL labels it `OTHER` and the case-folded noun
`Hub` therefore outranks verb `heben`. Finite `steht … auf` remains absent until
C08b recombination. These results are reproduced with:

```sh
.cache/contextual/.venv/bin/python \
  scripts/dictionary/contextual/evaluate_german_corpus.py \
  --form-inventory tmp.local/german-wiktionary.cpdict
```

The inventory is desktop-only. Loading it constructs exact and folded Python
indexes once so full-book analysis performs O(1) form lookup without repeated
archive reads. This host heap cost does not change firmware, EPUB, or SD-card
RAM budgets.

## Decision

The Open Edition is sufficient as the deterministic inflection and
word-formation backbone, but not as the sole production candidate lexicon. The
pipeline must augment missing DWDSmor candidates offline from the retained
Wiktionary/de-DE form inventory, then let the same contextual policy rank the
union. This fallback does not change firmware cost because only resolved
canonical IDs enter `language.bin`.

Finite separable verbs need a dedicated sentence-level recombination rule.
Contextual-model errors such as imperative *Liebe* remain visible in this corpus
and must be compared against the transformer model or corrected by a narrowly
documented scoring rule in C10. Production cutover remains blocked until these
failures have explicit behavior and broader novel coverage is measured.
